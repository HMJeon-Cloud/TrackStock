# StockMind 화면 검사 (배포 전 로컬 실행)

가짜 시세·가짜 뉴스로 로컬 서버를 띄우고 Playwright(크롬)로 화면을 열어 **겹침·넘침·콘솔 오류**를 검사합니다.
실제 API·키는 전혀 쓰지 않습니다. Vercel 배포와 무관하며 이 폴더는 배포에 포함돼도 동작에 영향이 없습니다.

## 준비 (한 번만)
```
cd tests
npm install
npx playwright install chromium
```

## 실행
| 명령 | 내용 | 통과 기준 |
|---|---|---|
| `npm run sweep` | 29개 화면 × 3폭(390/768/1280) 겹침·넘침 검사 | 마지막 줄 `오류 0 []` |
| `npm run daily` | 오늘 탭(전체 시장 요약) + 데일리 9장 카드 생성 | `cards 9`, `오류 0` |
| `npm run report` | 리포트(시장/종목) 전시·종합 해석 | `오류 0` |
| `npm run analyst` | 애널리스트 페이지 · 기록 · 보정 | `오류 0` |
| `npm run all` | 위 네 개 순서대로 | |

스크린샷은 `tests/pf/` 에 저장됩니다(깃에 올릴 필요 없음).
포트 878x–880x 를 씁니다. 이미 쓰고 있으면 스크립트 안의 포트 숫자를 바꾸세요.
